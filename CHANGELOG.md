# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2025-XX-XX
### Added
- Initial release.
- Strang split-step Fourier solver for the 1D Schrödinger equation.
- Fourier Neural Operator (FNO) PyTorch implementation with real/imaginary channel handling.
- In-Distribution (ID) and Out-of-Distribution (OOD) dataset generators.
- Autoregressive rollout and norm-drift evaluation metrics.
- Dockerfile and GitHub Actions CI pipeline.
- Comprehensive README with mathematical derivations and honest failure reporting.
